# Job Market Data Analysis Dashboard

## Project Overview

This project analyzes job market data to identify hiring trends, company-wise job postings, location-based opportunities, and salary distributions. The analysis was performed using Microsoft Excel for data preparation and Power BI for creating an interactive dashboard.

## Objectives

- Analyze job postings across different locations.
- Identify the top companies with the highest number of job openings.
- Examine salary range distributions in the job market.
- Build an interactive dashboard for data-driven insights.

## Tools Used

- Microsoft Excel
- Power BI

## Dashboard Features

### KPI Cards
- Total Job Postings
- Total Companies
- Total Locations

### Visualizations
- Jobs by Location
- Top Companies Hiring
- Salary Range Distribution

### Interactive Filters
- Location
- Company
- Job Title

## Dataset Information

The dataset contains job listing information, including:
- Job ID
- Job Title
- Company Name
- Location
- Salary Range

## Project Workflow

### Data Cleaning in Excel
- Removed duplicate records.
- Handled missing values.
- Standardized data formats.
- Prepared the dataset for analysis.

### Dashboard Development in Power BI
- Imported the cleaned dataset.
- Created KPI cards and charts.
- Added interactive slicers.
- Designed an interactive dashboard.

## Key Insights

- Identified locations with the highest number of job opportunities.
- Highlighted companies with the most active hiring.
- Analyzed salary range distribution across job postings.
- Enabled interactive exploration of job market trends.
